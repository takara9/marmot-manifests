# Keycloak で出来ること

Keycloak は、オープンソースの ID・アクセス管理（IAM）基盤です。主にできることは次のとおりです。

## 認証・シングルサインオン
- **SSO（シングルサインオン）/ シングルログアウト**: 複数アプリへ一度のログインでアクセスできます。
- **標準プロトコル対応**: OpenID Connect (OIDC)、OAuth 2.0、SAML 2.0 に対応します。
- **多要素認証 (MFA)**: TOTP（Google Authenticator など）、WebAuthn/Passkey、リカバリーコードを使えます。
- **パスワードレス認証**: WebAuthn/Passkey によるログインに対応します。
- **ブルートフォース対策**: ログイン失敗時のアカウントロック、パスワードポリシー（長さ・複雑さ・履歴・有効期限）を設定できます。

## ユーザー管理
- **ユーザー/グループ/ロール管理**: 管理コンソールまたは REST API で操作できます。
- **セルフサービス**: ユーザー登録、パスワード忘れ対応、メール検証、アカウント管理画面を提供します。
- **ユーザー属性・必須アクション**: 初回ログイン時のパスワード変更、規約同意などを設定できます。

## 外部連携（フェデレーション）
- **LDAP / Active Directory 連携**: 既存ディレクトリのユーザーを利用できます。
- **ソーシャルログイン**: Google、GitHub、Microsoft、Facebook など。
- **Identity Brokering**: 外部の OIDC/SAML IdP を経由してログインできます。
- **Kerberos 連携**: 社内ドメインでの統合認証に対応します。

## 認可
- **ロールベース (RBAC)**、**グループベース**のアクセス制御ができます。
- **Authorization Services**: 細粒度のリソース/スコープ/ポリシー/パーミッション管理ができます（ABAC 的な制御を含みます）。
- **Token Exchange**、**Service Account**（Client Credentials）で、マシン間認証を行えます。

## マルチテナント・カスタマイズ
- **Realm**: 組織やテナントごとに設定・ユーザーを分離できます。
- **テーマ**: ログイン画面などの見た目をカスタマイズできます。
- **SPI（拡張機構）**: 認証フロー、ユーザーストレージ、イベントリスナーなどを Java で拡張できます。
- **認証フローのカスタマイズ**: 条件付き MFA や独自のステップを追加できます。

## 運用・セキュリティ
- **イベント/監査ログ**: ログイン、管理操作の記録ができます。
- **クラスタリング・高可用性**: Infinispan を使い、PostgreSQL などの DB と組み合わせます。
- **メトリクス・ヘルスチェック**: Prometheus 形式で出力できます。
- **管理 API / CLI（kcadm）**: 自動化や IaC 連携に使えます。
- **配備形態**: systemd、コンテナ、Kubernetes（Operator）に対応します。

## 典型的な用途
- 社内アプリ・SaaS の SSO 基盤
- API ゲートウェイ/マイクロサービスのトークン発行（JWT）
- CIAM（顧客向けログイン基盤）
- Kubernetes/Grafana/GitLab などの OIDC ログイン連携
